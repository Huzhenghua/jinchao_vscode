# 现代化 UI 设计优化 Spec（v2）

## Why
B 站风格改造完成了功能层面，但界面存在双重短板：**视觉表现力不足**——无渐变层次、导航平淡、卡片缺乏光感细节、空状态/加载态粗糙；**工程质量欠账**——导航双轨不统一（14 页旧式 / 2 页新式）、深色模式 CSS 无切换入口（死代码）、仅 2 处响应式断点、19 处 `window.alert`、emoji 充当图标、内联样式散落。需要一次以「视觉现代化 + 体验现代化」为纲的系统优化，在保持 B 粉品牌与全部现有功能不变的前提下，让界面达到现代设计标准的视觉吸引力与专业一致性。

## 设计方向（Design Language）
- **玻璃拟态导航**：吸顶导航 `backdrop-filter` 毛玻璃 + 半透明底，滚动时微妙加深
- **渐变设计语言**：以 B 粉为锚的双色渐变（`#fb7299 → #ff9ab5` / 深色态相应调整）应用于主按钮、分区 Tab 激活态、节标题强调条、进度条；拒绝大面积滥用，仅做点睛
- **光感与层次**：卡片 hover 浮起 + 柔和大阴影、封面底部渐变遮罩保证角标可读、圆角体系统一（卡片 12px / 按钮 8px）
- **克制的动效**：入场淡入上移、hover 位移 ≤4px、弹幕/骨架屏尊重 reduced-motion

## What Changes
- **设计令牌系统**：排版比例（type scale）、间距刻度（4px 基准）、语义色（成功/警告/错误）、渐变令牌、阴影三级、统一 z-index；浅深两套全量覆盖
- **玻璃拟态导航 + 渐变语言**：全站导航视觉升级；主按钮/激活态/强调条统一渐变体系
- **深色模式落地**：导航切换按钮 + localStorage 持久化 + 首访跟随 `prefers-color-scheme`；深色态为「B 站黑底粉」高级感（纯黑播放器区 + 粉色高光）
- **首页视觉升级**：顶部 hero 横幅区（渐变背景 + 站点 slogan/数据概览）、分区 Tab 胶囊化（渐变激活态）、区块节奏统一
- **视频卡片精修**：封面底部渐变遮罩、时长/播放量角标统一、hover 浮起 + 阴影、UP 主行排版精修、标题 2 行截断
- **详情页视觉精修**：播放器区域暗色沉浸、右侧信息卡圆角化、操作按钮组（点赞/收藏/关注）渐变主次分明
- **空状态与加载态**：统一的空状态组件（居中图标 + 文案 + 引导按钮）；骨架屏（微光动画）替代"加载中..."文本
- **Toast 通知**：替换全部 19 处 `window.alert`，成功/错误样式 + 自动消失 + 多条叠加
- **内联 SVG 图标**：关键交互位（导航/按钮/Tab/空状态）emoji 替换为统一线条风格 SVG，零外部依赖
- **导航统一**：全部 17 页统一结构（Logo + 居中搜索 + 右侧动作区 + 主题切换）；移动端汉堡菜单
- **响应式增强**：三档断点（≤560 / ≤900 / ≥1200）复核补齐：网格列数自适应、详情页移动端堆叠、触控目标 ≥44px
- **信息层级**：`.section-header` 组件（渐变强调条 + 标题 + 更多链接）、清理布局类内联样式、统一留白节奏
- **可访问性**：`focus-visible` 焦点样式、图标 `aria-label`、正文对比度达 WCAG AA

### 明确不变（约束）
- 不改任何后端 API / 数据库
- 保持 B 粉主色 `#fb7299` 品牌识别
- 保留 app.js 依赖的全部 DOM 钩子（ID/类名）；导航统一时同步改造 `updateNavigation()` 为单一代码路径
- 不引入前端框架、外部图标库或网络字体（保持离线/局域网可用）；`backdrop-filter` 提供不支持时的纯色降级

## Impact
- Affected specs: transform-to-bilibili-style-video（UI 层延续升级，不推翻其任何功能）
- Affected code:
  - `public/css/style.css` — 设计令牌扩展 + 视觉语言与全组件样式升级（主战场）
  - `public/*.html` — 17 页导航统一、hero 区/骨架屏/空状态占位、内联样式清理
  - `public/js/app.js` — 主题切换、toast、空状态渲染、updateNavigation 简化、图标注入
  - 不影响：server.js、database.js、全部后端逻辑

## ADDED Requirements

### Requirement: 玻璃拟态导航
吸顶导航 SHALL 采用毛玻璃效果（半透明背景 + `backdrop-filter: blur`），滚动时背景加深，不支持 `backdrop-filter` 的环境降级为不透明白/深色底。

#### Scenario: 滚动时的导航
- **WHEN** 页面向下滚动
- **THEN** 导航保持吸顶，背景半透明毛玻璃且边框/阴影轻微加深，内容从其下方透出模糊质感

### Requirement: 渐变设计语言
主按钮、分区 Tab 激活态、节标题强调条、关注按钮 SHALL 使用统一的 B 粉渐变令牌，浅深两套主题各有一致定义。

#### Scenario: 主按钮渲染
- **WHEN** 页面出现主操作按钮（如登录、发布、关注）
- **THEN** 按钮呈现粉渐变底 + 白字 + hover 微亮效果，全站一致

### Requirement: 首页 Hero 区
首页 SHALL 在分区 Tab 之上提供 hero 横幅（渐变背景 + 站点标语/简要数据），移动端等比缩放不溢出。

#### Scenario: 打开首页
- **WHEN** 用户访问 `/`
- **THEN** 第一屏自上而下为：玻璃导航 → hero 横幅 → 分区 Tab（胶囊化）→ 视频推荐流

### Requirement: 视频卡片视觉规范
视频卡片 SHALL 具备：封面底部渐变遮罩、统一时长角标、hover 浮起 + 阴影加深、标题 2 行截断、UP 主行（头像 + 昵称 + 播放量）排版统一。

#### Scenario: 悬停卡片
- **WHEN** 用户鼠标悬停视频卡片
- **THEN** 卡片轻微上浮（≤4px）+ 阴影加深 + 封面轻微放大，过渡 0.2-0.3s

### Requirement: 空状态组件
列表无内容时 SHALL 显示统一空状态（居中 SVG 图标 + 说明文案 + 引导按钮，如"去关注 UP 主"）。

#### Scenario: 关注动态为空
- **WHEN** 用户未关注任何人访问 `/following.html`
- **THEN** 显示空状态组件引导去浏览视频/关注 UP 主，而非空白或纯文本

### Requirement: 深色模式切换
系统 SHALL 提供导航栏深色/浅色切换按钮，选择持久化到 localStorage，首次访问跟随系统 `prefers-color-scheme`；深色态全组件可读。

#### Scenario: 切换深色模式
- **WHEN** 用户点击导航栏主题切换按钮
- **THEN** `body` 挂载/移除 `dark` 类，全站即时切换，刷新后保持上次选择

### Requirement: Toast 通知
系统 SHALL 以自动消失的 toast 替代全部 `window.alert`，区分成功/错误样式，支持多条叠加。

#### Scenario: 操作失败提示
- **WHEN** 任一原 alert 场景触发（如弹幕发送失败）
- **THEN** 显示对应样式 toast，数秒后自动消失，不阻断页面操作

### Requirement: 骨架屏加载
列表类内容加载中 SHALL 显示与最终布局同构的骨架占位（微光动画），而非纯文本。

#### Scenario: 首页视频流加载
- **WHEN** 视频推荐流请求未返回
- **THEN** 视频网格区显示骨架卡片，数据到达后无缝替换

### Requirement: 统一导航
全部页面 SHALL 使用同一导航结构（Logo + 居中搜索 + 右侧动作区 + 主题切换按钮）。

#### Scenario: 移动端导航
- **WHEN** 视口 ≤560px
- **THEN** 动作区链接折叠进汉堡菜单，搜索保持可用，展开菜单包含全部入口与登录/注册

### Requirement: 内联 SVG 图标
关键交互位置 SHALL 使用统一线条风格的内联 SVG 图标替代 emoji，无外部网络请求。

#### Scenario: 导航图标渲染
- **WHEN** 页面渲染导航栏
- **THEN** 通知/私信/主题切换等入口显示 SVG 图标并带 `aria-label`

### Requirement: 响应式三档适配
全站 SHALL 在手机（≤560px）、平板（≤900px）、桌面（≥1200px）断点下布局合理、无横向滚动。

#### Scenario: 手机浏览详情页
- **WHEN** 视口 ≤560px 访问视频详情页
- **THEN** 播放器与信息栏纵向堆叠，操作按钮组换行不溢出

## MODIFIED Requirements

### Requirement: 设计令牌系统（升级现有 CSS 变量组）
在现有颜色变量基础上扩展完整令牌：排版比例（`--text-xs` ~ `--text-2xl` + 字重）、间距刻度（`--space-1` ~ `--space-8`，4px 基准）、语义色（`--success/--warning/--danger` 及浅色底变体）、渐变令牌（`--primary-gradient` 及 hover 态）、阴影三级（`--shadow-sm/md/lg`）、玻璃导航令牌（`--nav-bg/--nav-blur`）；两套主题全量覆盖，新增样式一律引用令牌。

### Requirement: 信息层级与页面节奏
各页散落的 h2+emoji+内联样式节标题 SHALL 替换为 `.section-header` 组件（渐变强调条 + 标题 + 更多链接）；布局类内联样式清理为类；容器留白统一由间距刻度控制。

### Requirement: 动画与动效（升级现有 transition）
现有零散 transition 升级为成体系的微交互：卡片/按钮悬停精修、区块入场淡入上移；全部动画在 `prefers-reduced-motion` 下降级为无位移/无闪烁（含既有弹幕飘动动画提供开关降级）。

## REMOVED Requirements
（无移除 —— 不删除任何现有功能、页面或后端能力）
