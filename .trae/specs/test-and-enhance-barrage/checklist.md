# Checklist

## 测试基线
- [x] 弹幕功能基线测试覆盖发送、显示、滚动、速度、颜色五类能力
- [x] 测试覆盖未登录 / 普通用户 / 管理员 / 操作他人弹幕四类用户场景
- [x] 测试覆盖 1440 / 1093 / 1000 / 768 / 640 / 390 六档视口宽度
- [x] 测试覆盖 Chromium（Chrome、Edge）与 Gecko（Firefox）浏览器
- [x] Safari 被明确标注为「未验证」而非通过
- [x] `docs/barrage/test-report.md` 含可复现步骤、期望/实际与结论，缺陷可追溯

## 缺陷修复
- [x] 关闭弹幕后持续播放不产生 DOM 累积，重新开启不集中爆发
- [x] 进度回退不会把已播弹幕一次性重刷
- [x] `POST /api/barrages` 已挂速率限制（30 次 / 15 分钟）
- [x] `offsetMs` 有上下界校验，负值与超大值被拒绝或归一化
- [x] 每一条被修复的缺陷在报告中都有复现证据与复测结论

## 数据与校验
- [x] `barrages` 表新增 `color`、`font_size`、`speed`、`updated_at` 四列，迁移对存量数据生效
- [x] 样式取值受白名单约束（12 色、字号 18/25/32、速度 slow/normal/fast）
- [x] 服务端对样式入参做强制校验，不信任前端传入值
- [x] 非法颜色无法进入内联样式（无 CSS 注入面）
- [x] 弹幕校验纯函数有单元测试，`npm test` 全部通过

## 接口与权限
- [x] `GET /api/barrages/:videoId` 返回 `id`、`user_id`、样式字段、`isOwn`、`canEdit`
- [x] `PATCH /api/barrages/:id` 支持内容/颜色/字号/速度部分更新并写入 `updated_at`
- [x] `DELETE /api/barrages/:id` 可删除弹幕
- [x] 未登录写请求被拒绝且不修改数据
- [x] 非发送者且非管理员写请求返回 403 且数据不变
- [x] 管理员可编辑与删除他人弹幕
- [x] PATCH / DELETE 同样受速率限制约束

## 前端能力
- [x] 发送栏提供颜色 / 字号 / 速度预设选择器，选择结果持久化并在再次进入时回填
- [x] 发送的弹幕携带预设样式并立即以该样式飘出
- [x] 「我的弹幕」管理面板按时间轴列出可管理弹幕，含空状态
- [x] 面板中可对弹幕执行编辑与删除（删除有二次确认）
- [x] 点击播放器中自己的弹幕可进入就地编辑，动画暂停并高亮
- [x] 点击他人弹幕不产生编辑行为
- [x] 编辑浮层支持保存 / 删除 / 取消，`Esc` 可关闭，取消后样式回滚
- [x] 保存编辑后在屏弹幕的文本与颜色/字号/时长立即更新，无需刷新
- [x] 编辑不在屏的弹幕，播放进度再次经过其时间点时按新样式渲染
- [x] 删除后播放器内在屏元素与面板列表项同时消失
- [x] 同一时间的多条弹幕分配不同轨道，无大面积重叠

## 视觉与无障碍
- [x] 弹幕、编辑浮层、管理面板样式复用 `:root` 设计令牌
- [x] 补 1000px 与 640px 断点，6 档视口下无横向溢出
- [x] `prefers-reduced-motion` 下不渲染飘动弹幕，但管理面板仍可编辑
- [x] 编辑浮层与面板可键盘操作，焦点可见
- [x] 编辑/删除结果通过 `aria-live="polite"` 播报
