# 密码修改（邮箱验证链接）+ 多文件上传 实现方案

> 面向执行模型：**MIMO 9B**。本方案刻意写成"照抄即可"的形式：涉及新增/改写的位置都给出**完整代码**，涉及 UI 的位置都给出**完整 HTML 骨架 + CSS + 尺寸说明**。
> 执行时请**严格按本方案**，不要自行发挥、不要顺手重构无关代码。凡本方案未提到的文件，一律不要修改。

## 1. 目标与范围

### 功能一：密码修改（必须含邮箱验证链接）

1. 用户提交"修改密码"请求后，系统向**用户注册邮箱**发送一封包含**唯一验证链接**的邮件。
2. 用户点击邮件里的链接 → 进入密码重置页面。
3. 在重置页设置新密码，提交后密码更新成功。
4. 修改完成后，再向该邮箱发送一封\*\*"密码已更新"通知邮件\*\*。

**入口范围（需求方已确认）：两者都做，共用同一套"链接令牌"流程**

* 入口 A：已登录用户在 `dashboard.html` 的「账号安全」区点击「修改密码」→ 系统自动向其注册邮箱发链接。

* 入口 B：未登录用户在 `login.html` 点击「忘记密码」→ 输入注册邮箱 → 系统发链接。

* 两个入口最终都落到同一个页面 `reset-password.html?token=xxx`。

### 功能二：多文件上传

1. 一次可选择并上传**多个文件**，显示**实时上传进度**与**每个文件的状态**。
2. **图片**：上传时自动生成缩略图（**统一 200×200 像素、保持原图比例不变**），以**九宫格布局**展示；点击缩略图可**查看原图**。
3. **音频**：上传完成后显示**自定义音频播放器**，支持播放/暂停、进度条拖动、音量调节。
4. **格式验证**：所有文件都要校验格式，非法格式给出**清晰的中文错误提示**。

**落地位置（需求方已确认）：升级** **`dashboard.html`** **现有「文件」面板为多文件上传；标题/密码按批次统一。**

## 5.4 后端辅助函数 —— `server.js`

```js
// ===== 密码修改（链接令牌）=====

// 生成 64 位十六进制随机令牌（只在邮件链接里出现，不落库明文）
function generateResetToken() {
  return crypto.randomBytes(32).toString('hex');
}

// 令牌哈希：库里只存哈希，降低数据库泄露风险
function hashResetToken(token) {
  return crypto.createHash('sha256').update(String(token)).digest('hex');
}

// 邮件链接的站点根地址：优先配置项，其次用请求 Host
function siteBaseUrl(req) {
  return config.baseUrl || `${req.protocol}://${req.get('host')}`;
}

// 校验令牌，返回命中的记录（未使用且未过期）或 undefined
function findValidResetToken(token) {
  const tokenHash = hashResetToken(token);
  return db.prepare(`
    SELECT id, user_id FROM password_reset_tokens
    WHERE token_hash = ? AND used_at IS NULL AND expires_at > ?
    ORDER BY created_at DESC LIMIT 1
  `).get(tokenHash, new Date().toISOString());
}

// 邮箱脱敏显示：abc@qq.com -> a**@qq.com
function maskEmail(email) {
  const value = String(email || '');
  const atIndex = value.indexOf('@');
  if (atIndex <= 0) return value;
  const name = value.slice(0, atIndex);
  const domain = value.slice(atIndex);
  const head = name.slice(0, 1);
  return `${head}${'*'.repeat(Math.max(1, name.length - 1))}${domain}`;
}
```

## 5.5 后端三个接口 —— `server.js`

**位置**：紧接着 `POST /api/reset-password`（L453-L484）之后插入（不要改动原有那段）。

### 接口 1：申请发送验证链接

```js
// 申请密码修改：登录用户走会话，未登录用户走邮箱；两种入口共用同一套令牌
app.post('/api/password-reset/request', async (req, res) => {
  let user = null;

  if (req.session.userId) {
    // 入口 A：已登录（dashboard「修改密码」），不看请求体，直接用会话身份
    user = db.prepare('SELECT id, email FROM users WHERE id = ?').get(req.session.userId);
    if (!user) {
      return res.json({ success: false, message: '登录已失效，请重新登录' });
    }
  } else {
    // 入口 B：未登录（登录页「忘记密码」），需要提供注册邮箱
    const email = normalizeEmail(req.body.email);
    if (!validateEmail(email)) {
      return res.json({ success: false, message: '请输入有效的邮箱地址' });
    }
    user = db.prepare('SELECT id, email FROM users WHERE email = ?').get(email);
    if (!user) {
      return res.json({ success: false, message: '该邮箱尚未注册' });
    }
  }

  // 作废旧令牌，保证同一时间只有一个有效链接
  db.prepare('DELETE FROM password_reset_tokens WHERE user_id = ?').run(user.id);

  const token = generateResetToken();
  const expiresAt = new Date(Date.now() + 30 * 60 * 1000).toISOString();
  db.prepare('INSERT INTO password_reset_tokens (user_id, token_hash, expires_at) VALUES (?, ?, ?)')
    .run(user.id, hashResetToken(token), expiresAt);

  const resetUrl = `${siteBaseUrl(req)}/reset-password.html?token=${token}`;

  try {
    await sendPasswordResetEmail(user.email, resetUrl, 30);
    res.json({
      success: true,
      message: `密码修改链接已发送至 ${maskEmail(user.email)}，30 分钟内有效`,
    });
  } catch (error) {
    // 发送失败则回收刚写入的令牌，避免留下永远收不到的无效令牌
    db.prepare('DELETE FROM password_reset_tokens WHERE user_id = ?').run(user.id);
    console.error('发送密码修改邮件失败:', error);
    res.json({ success: false, message: '发送验证邮件失败，请稍后重试' });
  }
});
```

```js
// 校验令牌是否可用：仅返回脱敏邮箱，不泄露账号信息
app.get('/api/password-reset/verify', (req, res) => {
  const token = String(req.query.token || '').trim();
  if (!token) {
    return res.json({ success: false, message: '缺少验证令牌' });
  }

  const record = findValidResetToken(token);
  if (!record) {
    return res.json({ success: false, message: '链接无效或已过期，请重新申请' });

  const user = db.prepare('SELECT email FROM users WHERE id = ?').get(record.user_id);

    return res.json({ success: false, message: '账号不存在' });
  }

  res.json({ success: true, email: maskEmail(user.email) });
});
```

### 接口 3：提交新密码

```js
// 提交新密码：令牌单次使用，成功后撤销所有登录会话并发送通知邮件
app.post('/api/password-reset/confirm', async (req, res) => {
  const token = String(req.body.token || '').trim();
  const password = String(req.body.password || '');

  if (!token) {
    return res.json({ success: false, message: '缺少验证令牌' });
  }

  if (!password || password.trim().length < 8) {
    return res.json({ success: false, message: '密码至少为8位字符' });
  }

  const record = findValidResetToken(token);
  if (!record) {
    return res.json({ success: false, message: '链接无效或已过期，请重新申请' });
  }

  const user = db.prepare('SELECT id, email FROM users WHERE id = ?').get(record.user_id);
  if (!user) {
    return res.json({ success: false, message: '账号不存在' });
  }

  const hashedPassword = await bcrypt.hash(password, 10);
  db.prepare('UPDATE users SET password = ? WHERE id = ?').run(hashedPassword, user.id);

  // 令牌单次使用：标记已用，同时清掉该用户其余令牌
  db.prepare('UPDATE password_reset_tokens SET used_at = ? WHERE id = ?').run(utcNow(), record.id);
  db.prepare('DELETE FROM password_reset_tokens WHERE user_id = ? AND id != ?').run(user.id, record.id);

  // 安全收尾：清除登录失败锁定，撤销全部登录会话（强制用新密码重新登录）
  clearLoginFail(user.email);
  db.prepare('UPDATE user_sessions SET revoked = 1 WHERE user_id = ?').run(user.id);

  // 通知邮件失败不影响本次修改结果
  try {
    await sendPasswordChangedEmail(user.email);
  } catch (error) {
    console.error('发送密码更新通知邮件失败:', error);
  }

  res.json({ success: true, message: '密码修改成功，请使用新密码登录' });
});
```

```js
// ===== 密码修改（邮箱验证链接）=====

// 读取当前 URL 的查询参数（仅用于 reset-password.html 取 token）
function getUrlParam(name) {
  return new URLSearchParams(window.location.search).get(name) || '';
}

// 入口 B：登录页「忘记密码」提交
async function handleForgotPassword(event) {
  event.preventDefault();
  const form = event.target;
  const email = document.getElementById('email').value.trim().toLowerCase();
  const submitButton = form.querySelector('button[type="submit"]');

  if (!email) {
    showMessage('forgot-message', '请输入邮箱', true);
    return;
  }

  submitButton.disabled = true;
  submitButton.textContent = '发送中...';
  try {
    const response = await fetch(`${API_BASE}/api/password-reset/request`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email }),
    });
    const data = await response.json();
    showMessage('forgot-message', data.message, !data.success);
    if (data.success) form.reset();
  } catch (error) {
    showMessage('forgot-message', '发送失败，请重试', true);
  } finally {
    submitButton.disabled = false;
    submitButton.textContent = '发送验证链接';
  }
}

// 入口 A：dashboard「修改密码」按钮（已登录，不带请求体）
async function requestPasswordReset() {
  const button = document.getElementById('request-password-reset');
  if (button) {
    button.disabled = true;
    button.textContent = '发送中...';
  }
  try {
    const response = await fetch(`${API_BASE}/api/password-reset/request`, { method: 'POST' });
    const data = await response.json();
    showMessage('password-reset-message', data.message, !data.success);
  } catch (error) {
    showMessage('password-reset-message', '发送失败，请重试', true);
  } finally {
    if (button) {
      button.disabled = false;
      button.textContent = '修改密码';
    }
  }
}

// reset-password.html 载入时校验令牌
async function initResetPasswordPage() {
  const form = document.getElementById('reset-form');
  const accountBox = document.getElementById('reset-account');
  const token = getUrlParam('token');

  if (!form || !token) {
    if (form) form.hidden = true;
    showMessage('reset-message', '链接不完整，请从邮件中的链接重新进入', true);
    return;
  }

  try {
    const response = await fetch(`${API_BASE}/api/password-reset/verify?token=${encodeURIComponent(token)}`);
    const data = await response.json();

    if (!data.success) {
      form.hidden = true;
      showMessage('reset-message', data.message, true);
      return;
    }

    if (accountBox) {
      accountBox.textContent = `正在为账号 ${data.email} 设置新密码`;
      accountBox.hidden = false;
    }
    form.hidden = false;
    showMessage('reset-message', '', false);
  } catch (error) {
    form.hidden = true;
    showMessage('reset-message', '链接校验失败，请重试', true);
  }
}

// 提交新密码
async function handleConfirmResetPassword(event) {
  event.preventDefault();
  const form = event.target;
  const token = getUrlParam('token');
  const password = document.getElementById('password').value;
  const confirmPassword = document.getElementById('confirm-password').value;
  const submitButton = form.querySelector('button[type="submit"]');

  if (password !== confirmPassword) {
    showMessage('reset-message', '两次输入的密码不一致', true);
    return;
  }

  submitButton.disabled = true;
  submitButton.textContent = '提交中...';
  try {
    const response = await fetch(`${API_BASE}/api/password-reset/confirm`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ token, password }),
    });
    const data = await response.json();
    showMessage('reset-message', data.message, !data.success);
    if (data.success) {
      setTimeout(() => { window.location.href = '/login.html'; }, 1600);
    }
  } catch (error) {
    showMessage('reset-message', '修改失败，请重试', true);
  } finally {
    submitButton.disabled = false;
    submitButton.textContent = '确认修改';
  }
}
```

## 5.12 端到端时序（自测时照此核对）

**入口 A（已登录）**

1. 登录 → 打开 `dashboard.html` → 滚到「账号安全」→ 点「修改密码」
2. `POST /api/password-reset/request`（带会话 Cookie，无请求体）
3. 邮箱收到「烬潮博客 - 密码修改验证」邮件 → 点「设置新密码」
4. 打开 `/reset-password.html?token=xxx` → 自动 `GET /api/password-reset/verify?token=xxx`
5. 页面显示脱敏邮箱 + 新密码表单 → 填两次新密码 → 提交
6. `POST /api/password-reset/confirm` → 成功 → 1.6 秒后跳转 `/login.html`
7. 邮箱收到「烬潮博客 - 密码已更新」通知
8. 用新密码可登录；旧密码登录失败

**入口 B（未登录）**

1. 打开 `login.html` → 点「通过邮箱重置」→ `/forgot-password.html`
2. 输入注册邮箱 → 提交 → 后续步骤与入口 A 的 3\~8 完全一致

**异常路径核对**

| 场景        | 预期                           |
| --------- | ---------------------------- |
| 邮箱未注册     | `该邮箱尚未注册`                    |
| 邮箱格式非法    | `请输入有效的邮箱地址`                 |
| 链接超 30 分钟 | 重置页显示 `链接无效或已过期，请重新申请`，且表单隐藏 |
| 链接已用过一次   | 同上（`used_at` 已置位）            |
| 重复申请      | 旧链接立即失效，只有最新链接可用             |
| 新密码 < 8 位 | `密码至少为8位字符`                  |
| 两次密码不一致   | 前端拦截：`两次输入的密码不一致`（不发请求）      |
| 未配置邮箱账号   | `发送验证邮件失败，请稍后重试`（控制台有详细错误）   |

```js
// ===== 文件上传格式白名单 =====

// 明确禁止的可执行/脚本类扩展名
const DANGEROUS_FILE_EXTENSIONS = [
  '.exe', '.bat', '.cmd', '.sh', '.ps1', '.msi', '.dll',
  '.scr', '.com', '.vbs', '.jar', '.app', '.apk',
];

// 允许上传的扩展名（按类别组织，前端也会镜像同一份白名单）
const ALLOWED_FILE_TYPES = {
  image: ['.jpg', '.jpeg', '.png', '.gif', '.webp', '.bmp'],
  audio: ['.mp3', '.wav', '.ogg', '.m4a', '.aac', '.flac'],
  video: ['.mp4', '.webm', '.mov', '.mkv'],
  document: ['.pdf', '.txt', '.md', '.csv', '.json', '.doc', '.docx', '.xls', '.xlsx', '.ppt', '.pptx', '.zip', '.rar', '.7z'],
};

const ALLOWED_FILE_EXTENSIONS = Object.values(ALLOWED_FILE_TYPES).flat();

// 校验单个文件：通过返回 null，不通过返回中文原因
function validateUploadFile(originalName) {
  const extension = path.extname(String(originalName || '')).toLowerCase();

  if (!extension) {
    return '文件名缺少扩展名，无法识别格式';
  }

  if (DANGEROUS_FILE_EXTENSIONS.includes(extension)) {
    return `出于安全考虑，不支持上传 ${extension} 类型的可执行文件`;
  }

  if (!ALLOWED_FILE_EXTENSIONS.includes(extension)) {
    return `不支持的文件格式（${extension}），仅支持图片、音频、视频、文档与压缩包`;
  }

  return null;
}
```

## 6.4 multer 改造 —— `server.js`

**替换**现有 `fileUpload` 定义（L119-L130）为下面这段。**`videoUpload`** **与** **`avatarUpload`** **保持不变。**

```js
// 多文件上传：files 为文件本体，thumbnails 为前端生成的图片缩略图
const fileUpload = multer({
  storage: multer.diskStorage({
    destination: (req, file, callback) => {
      callback(null, file.fieldname === 'thumbnails' ? thumbnailDirectory : fileDirectory);
    },
    filename: (req, file, callback) => {
      const extension = path.extname(file.originalname).toLowerCase();
      callback(null, `${Date.now()}-${Math.random().toString(36).slice(2)}${extension}`);
    },
  }),
  limits: {
    fileSize: 200 * 1024 * 1024, // 单个文件 200MB
    files: 40,                   // 最多 20 个文件 + 20 个缩略图
  },
  fileFilter: (req, file, callback) => {
    // 缩略图只允许图片
    if (file.fieldname === 'thumbnails') {
      return callback(null, String(file.mimetype).startsWith('image/'));
    }

    // 文件本体做格式校验：不合法则记录原因并跳过该文件（其余文件继续）
    const rejection = validateUploadFile(file.originalname);
    if (rejection) {
      req.rejectedFiles = req.rejectedFiles || [];
      req.rejectedFiles.push({ name: file.originalname, reason: rejection });
      return callback(null, false);
    }

    callback(null, true);
  },
});

// 包装 multer 中间件，把 multer 的错误转成统一 JSON
function fileUploadFields(req, res, next) {
  fileUpload.fields([{ name: 'files', maxCount: 20 }, { name: 'thumbnails', maxCount: 20 }])(req, res, error => {
    if (!error) return next();

    // 出错时清理本次已落盘的文件，避免留下垃圾
    if (req.files && typeof req.files === 'object') {
      Object.values(req.files).flat().forEach(item => {
        try { fs.rmSync(item.path, { force: true }); } catch (cleanupError) { /* 忽略清理失败 */ }
      });
    }

    if (error.code === 'LIMIT_FILE_SIZE') {
      return res.json({ success: false, message: '单个文件不能超过 200MB' });
    }
    if (error.code === 'LIMIT_FILE_COUNT' || error.code === 'LIMIT_UNEXPECTED_FILE') {
      return res.json({ success: false, message: '一次最多上传 20 个文件' });
    }
    return res.json({ success: false, message: `文件上传失败：${error.message}` });
  });
}
```

```js
const API_BASE_UPLOAD = '/api/files';
const MAX_UPLOAD_FILES = 20;
const THUMBNAIL_SIZE = 200;

// 与后端 validation.js 保持一致的白名单
const UPLOAD_DANGEROUS_EXTENSIONS = ['.exe', '.bat', '.cmd', '.sh', '.ps1', '.msi', '.dll', '.scr', '.com', '.vbs', '.jar', '.app', '.apk'];
const UPLOAD_ALLOWED_EXTENSIONS = [
  '.jpg', '.jpeg', '.png', '.gif', '.webp', '.bmp',
  '.mp3', '.wav', '.ogg', '.m4a', '.aac', '.flac',
  '.mp4', '.webm', '.mov', '.mkv',
  '.pdf', '.txt', '.md', '.csv', '.json', '.doc', '.docx', '.xls', '.xlsx', '.ppt', '.pptx', '.zip', '.rar', '.7z',
];

function fileExtensionOf(name) {
  const index = String(name || '').lastIndexOf('.');
  return index === -1 ? '' : String(name).slice(index).toLowerCase();
}

// 返回 null 表示通过，否则返回中文原因（文案与后端一致）
function validateUploadFileClient(file) {
  const extension = fileExtensionOf(file.name);
  if (!extension) return '文件名缺少扩展名，无法识别格式';
  if (UPLOAD_DANGEROUS_EXTENSIONS.includes(extension)) return `出于安全考虑，不支持上传 ${extension} 类型的可执行文件`;
  if (!UPLOAD_ALLOWED_EXTENSIONS.includes(extension)) return `不支持的文件格式（${extension}），仅支持图片、音频、视频、文档与压缩包`;
  return null;
}

// 文件类别：image / audio / video / other
function fileKindOf(mimeType) {
  const type = String(mimeType || '');
  if (type.startsWith('image/')) return 'image';
  if (type.startsWith('audio/')) return 'audio';
  if (type.startsWith('video/')) return 'video';
  return 'other';
}

function formatFileSize(bytes) {
  const size = Number(bytes) || 0;
  if (size < 1024) return `${size} B`;
  if (size < 1024 * 1024) return `${(size / 1024).toFixed(1)} KB`;
  return `${(size / 1024 / 1024).toFixed(1)} MB`;
}
```

### 6.9.2 缩略图生成（Canvas，200×200，保持比例）

```js
// 用 Canvas 生成 200×200 缩略图：等比缩放到框内并居中（contain），保持原图比例不变
function generateThumbnail(file, maxSize = THUMBNAIL_SIZE) {
  return new Promise((resolve, reject) => {
    const image = new Image();
    const objectUrl = URL.createObjectURL(file);

    image.onload = () => {
      try {
        const scale = Math.min(maxSize / image.width, maxSize / image.height);
        const drawWidth = Math.max(1, Math.round(image.width * scale));
        const drawHeight = Math.max(1, Math.round(image.height * scale));
        const offsetX = Math.round((maxSize - drawWidth) / 2);
        const offsetY = Math.round((maxSize - drawHeight) / 2);

        const canvas = document.createElement('canvas');
        canvas.width = maxSize;
        canvas.height = maxSize;
        const context = canvas.getContext('2d');
        context.fillStyle = '#ffffff';
        context.fillRect(0, 0, maxSize, maxSize);
        context.drawImage(image, offsetX, offsetY, drawWidth, drawHeight);

        URL.revokeObjectURL(objectUrl);
        canvas.toBlob(
          blob => (blob ? resolve(blob) : reject(new Error('缩略图生成失败'))),
          'image/jpeg',
          0.85,
        );
      } catch (error) {
        URL.revokeObjectURL(objectUrl);
        reject(error);
      }
    };

    image.onerror = () => {
      URL.revokeObjectURL(objectUrl);
      reject(new Error('图片读取失败'));
    };

    image.src = objectUrl;
  });
}
```

```js
async function handleFileUpload(event) {
  event.preventDefault();
  const form = event.target;
  const submitButton = form.querySelector('button[type="submit"]');

  const readyItems = selectedUploadFiles.filter(item => item.status === 'ready');

  }

  const password = String(document.getElementById('file-password').value || '').trim();

  formData.append('title', title);
  formData.append('password', password);

  const thumbnailIndexes = [];
  for (let index = 0; index < readyItems.length; index += 1) {

        console.warn('缩略图生成失败：', item.file.name, error.message);
      }
    }
  }
  formData.append('thumbnailIndexes', thumbnailIndexes.join(','));

  // 2) 队列状态改为"上传中"
  readyItems.forEach(item => updateQueueItemStatus(item.file.name, '上传中', false));

  // 3) 显示进度条
  const progressWrap = document.getElementById('file-progress-wrap');
  const progressFill = document.getElementById('file-progress-fill');
  const progressText = document.getElementById('file-progress-text');
  if (progressWrap) progressWrap.hidden = false;

  try {
    const data = await uploadFileBatch(formData, (percent) => {
      if (progressFill) progressFill.style.width = `${percent}%`;
      if (progressText) progressText.textContent = `${percent}%`;
    });

    showMessage('file-message', data.message, !data.success);

    if (data.success) {
      readyItems.forEach(item => updateQueueItemStatus(item.file.name, '上传成功', false));
      renderUploadResult(data.files || [], data.rejected || []);
      form.reset();
      selectedUploadFiles = [];
      const queue = document.getElementById('file-queue');
      if (queue) queue.innerHTML = '';
      await loadFileGallery();
    } else {
      readyItems.forEach(item => updateQueueItemStatus(item.file.name, '上传失败', true));
    }
  } catch (error) {
    showMessage('file-message', error.message || '上传失败，请重试', true);
    readyItems.forEach(item => updateQueueItemStatus(item.file.name, '上传失败', true));
  } finally {
    submitButton.disabled = false;
    submitButton.textContent = '上传文件';
    if (progressWrap) progressWrap.hidden = true;
    if (progressFill) progressFill.style.width = '0%';
    if (progressText) progressText.textContent = '0%';
  }
}

// 用 XMLHttpRequest 上传整批，以便监听真实上传进度（fetch 不支持上传进度）
function uploadFileBatch(formData, onProgress) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open('POST', API_BASE_UPLOAD, true);

    xhr.upload.onprogress = (event) => {
      if (!event.lengthComputable) return;
      const percent = Math.min(100, Math.round((event.loaded / event.total) * 100));
      onProgress(percent);
    };

    xhr.onload = () => {
      try {
        resolve(JSON.parse(xhr.responseText));
      } catch (error) {
        reject(new Error('服务器返回内容无法解析'));
      }
    };

    xhr.onerror = () => reject(new Error('网络异常，上传失败'));
    xhr.onabort = () => reject(new Error('上传已取消'));
    xhr.send(formData);
  });
}
```

```js
    if (player.dataset.audioReady === '1') return;
    player.dataset.audioReady = '1';

    const audio = player.querySelector('audio');
    const toggle = player.querySelector('.audio-player-toggle');
    const progress = player.querySelector('.audio-player-progress');
    const currentLabel = player.querySelector('[data-audio-current]');
    const durationLabel = player.querySelector('[data-audio-duration]');
    const volume = player.querySelector('.audio-player-volume');
    if (!audio || !toggle) return;

    audio.volume = 1;

    toggle.addEventListener('click', () => {
      if (audio.paused) {
        audio.play().catch(() => showToast('音频播放失败', 'error'));
      } else {
        audio.pause();
      }
    });

    audio.addEventListener('play', () => { toggle.textContent = '❚❚'; toggle.setAttribute('aria-label', '暂停'); });
    audio.addEventListener('pause', () => { toggle.textContent = '▶'; toggle.setAttribute('aria-label', '播放'); });
    audio.addEventListener('ended', () => { toggle.textContent = '▶'; progress.value = 0; if (currentLabel) currentLabel.textContent = '00:00'; });

    audio.addEventListener('loadedmetadata', () => {
      if (durationLabel && Number.isFinite(audio.duration)) durationLabel.textContent = formatDuration(audio.duration);
    });

    audio.addEventListener('timeupdate', () => {
      if (!Number.isFinite(audio.duration) || audio.duration === 0) return;
      progress.value = Math.round((audio.currentTime / audio.duration) * 1000);
      if (currentLabel) currentLabel.textContent = formatDuration(audio.currentTime);
    });

    // 拖动进度条跳转
    progress.addEventListener('input', () => {
      if (!Number.isFinite(audio.duration) || audio.duration === 0) return;
      audio.currentTime = (Number(progress.value) / 1000) * audio.duration;
    });

    // 音量调节
    if (volume) {
      volume.addEventListener('input', () => { audio.volume = Number(volume.value) / 100; });
    }
  });
}
```

```js
  const container = document.getElementById('file-gallery');

    const images = list.filter(file => fileKindOf(file.mime_type) === 'image');
    const audios = list.filter(file => fileKindOf(file.mime_type) === 'audio');

    if (images.length === 0 && audios.length === 0) {
      container.innerHTML = '';
      return;
    }

    container.innerHTML = `
      ${images.length ? `<h4 class="upload-result-title">图片（${images.length}）</h4>${fileGalleryMarkup(images)}` : ''}

    `;
    setupAudioPlayers(container);
  } catch (error) {
    container.innerHTML = '<p class="loading">文件库加载失败</p>';
  }
}
```

## 9. 假设与风险

| 项                                 | 说明                                                                     |
| --------------------------------- | ---------------------------------------------------------------------- |
| **前置依赖：邮箱配置**                     | 功能一的邮件发送强依赖 `.env` 里正确的 QQ 邮箱授权码。若未配置，接口会返回"发送验证邮件失败"。这不属于代码缺陷         |
| **前置依赖：`JINCHAO_SESSION_SECRET`** | 建议先修正 `.env` 第 6 行（当前是命令文本，不是真密钥）                                      |
| 缩略图前端生成的取舍                        | 优点：零依赖、跨平台。缺点：缩略图由客户端产出，理论上可被绕过（不影响安全，仅影响展示）                           |
| `thumbnailIndexes` 约定             | 前后端靠它对齐"第几个文件带缩略图"。**若前端改了 append 顺序，必须同步改这个字段**，这是本方案最容易出错的地方         |
| 部分成功语义                            | 一个批次里合法文件会真的入库，非法文件被跳过并在 `rejected` 返回。用户看到的提示会同时给出"成功 N 个"和"跳过 M 个"   |
| 音频播放依赖浏览器支持                       | 播放器用原生 `<audio>` 元素驱动，能否播放取决于浏览器对该格式的支持（mp3/wav/ogg 通常无问题，flac 视浏览器而定） |
| 未做的部分                             | 本方案不实现：密码强度可视化提示、上传断点续传、视频文件的播放器（视频已有独立流程）、缩略图的服务端回退生成                 |
